I spend my time learning new concepts, trying out tools, and practicing in virtual machines and security labs.

I'm particularly interested in understanding how vulnerabilities work, how systems can be attacked, and how they can be better protected.

I still have a lot to learn, and that's what makes this field interesting to me.
